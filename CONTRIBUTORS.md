## Upstream

moldordie is a fork of
[cookiecutter-django](https://github.com/cookiecutter/cookiecutter-django), and
most of the code in this repository was written by that project's maintainers
and contributors. Their roll is preserved in
[CONTRIBUTORS-cookiecutter-django.md](CONTRIBUTORS-cookiecutter-django.md), and
the copyright notice covering their work is in [LICENSE](LICENSE).

This file lists contributors to the fork only. It is maintained by hand; the
upstream automation that generated it from merged pull requests was removed
along with the rest of the machinery that only ran under the `cookiecutter`
organization.
