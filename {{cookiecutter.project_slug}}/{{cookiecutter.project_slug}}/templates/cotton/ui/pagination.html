{% raw %}{% comment %} Navigation between the pages of a Django page object. The view supplies the URLs: previous_url and next_url, and optionally page_urls, pairs of a page number and its URL (a pair with an empty URL is an ellipsis) which replace the "Page n of m" line. The current page carries aria-current; a previous or next that does not exist is written as text, not a link. With a target, a CSS selector, every link also asks htmx to load the page into that element, replacing it (hx-swap="outerHTML") and pushing the URL, so the target must contain both the results and this component and the fragment must reproduce it with its id. The label names the navigation for assistive technology. Every attribute the component does not declare is forwarded to the nav (docs/frontend.rst). {% endcomment %} {% load i18n %}
