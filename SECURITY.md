# Security Policy

## Supported Versions

Only the latest version of moldordie is supported.

## Reporting a Vulnerability

If you think you have found a vulnerability, and even if you are not sure, please [report it to us in private](https://github.com/matsakelarsson/moldordie/security/advisories/new). We will review it and get back to you. Please refrain from public discussions of the issue.

If the vulnerability is inherited from [cookiecutter-django](https://github.com/cookiecutter/cookiecutter-django) rather than introduced by this fork, please also [report it there](https://github.com/cookiecutter/cookiecutter-django/security/advisories/new), since their users are affected too.
